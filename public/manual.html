3. Installation (New Computer)

  1. Install Node.js from nodejs.org (LTS 20+)
  2. Copy unified-jomish-suite folder to client PC
  3. Double-click Start_Jomish_Suite.vbs (first run installs dependencies)
  4. Login with default credentials, change passwords
  5. Configure business name/logo in Settings
  6. Run Lock_System.vbs to hide source code
  7. Optionally run Enable_Startup.vbs for auto-start

4. Starting the System

Double-click Start_Jomish_Suite.vbs. It does:

  1. Kills all running node processes
  2. Installs dependencies if missing
  3. Starts server silently (no terminal)
  4. Polls server until ready (up to 18 seconds)
  5. Opens Chrome/Edge in kiosk mode (fullscreen, no address bar)
  6. Goes directly to login page
The minimize button (dark circle, top-right) is the ONLY way users can minimize the app.

5. Lock / Unlock System

Lock (After Deployment)

Run Lock_System.vbs — hides all internal folders using attrib +h +s. Even "Show hidden files" won't reveal them.

Unlock (For Maintenance)

Run Unlock_System.vbs → Enter Jomish9!! → All folders visible. Run Lock again when done.

10. Monthly Backup

  1. Insert flash drive
  2. Open backup/ folder
  3. Double-click Backup_Data.vbs
  4. Enter password: Jomish9!!
  5. Select flash drive in folder picker
  6. Wait for completion — server auto-restarts
  7. Store flash drive safely

Creates: jomish_backup_YYYY-MM-DD_HH-MM.db + .json metadata file.

11. Restore After Crash

  1. Install system on new/repaired computer (Section 3)
  2. Open backup/ folder
  3. Double-click Restore_Backup.vbs
  4. Enter password: Jomish9!!
  5. Select .db file from flash drive
  6. Confirm data loss warning
  7. System restores and starts automatically
Data between the backup date and the crash date is LOST. A red banner will appear in the app to acknowledge this.

Safety: current DB is saved as jomish_pre_restore_*.db before overwriting.

12. Applying Updates

  1. Send client the update file (e.g. update_1.1_feature.js)
  2. Client drops it into updates/ folder
  3. Double-click Apply_Update.vbs → password → done

Writing Update Files

Name: update_[version]_[description].js

module.exports = function(db, done) {
    db.run(`ALTER TABLE employees ADD COLUMN dept TEXT DEFAULT 'General'`,
    (err) => {
        if (err && err.message.includes('duplicate')) return done(null);
        if (err) return done(err);
        done(null);
    });
};

Rules: Always idempotent. Never DROP/DELETE. Use IF NOT EXISTS. Call done() when finished.
